PTE Describe Image (DI) 万能高分模板

为什么你需要 DI 模板？
流利度 > 发音 > 内容。
25 秒的准备时间内快速组织语言，并在 40 秒的答题时间内保持 5.0 语速不卡顿。

备考小贴士
不要纠结数据准确性：机器不核对你读的数字是否精确，只听你读得顺不顺。看到 "19,873" 读不出来？直接读 "about 20 thousand" 或者单纯读 "number 20"。
遇到生词怎么办：直接用 "something" 代替，或者随便读一个你认识的词，绝对不要卡顿。
保持匀速：不要忽快忽慢，全程保持平稳的语调和语速。
无脑套用：遇到地图题、流程图甚至无标题图，只要能抓到几个关键词，就往模板里套。

DI模板(30-35秒最佳),每天3道，练到65分：
[线line chart/ 饼pie chart/ 柱bar chart/ 表table]
要快速抓取数据，数据对应，数据趋势描述与总结；线图和柱图方便描述趋势（动态），饼图和表图方便做数据对比（静态）.
1.  In this [图片类型] we can get information about [主题/标题].
    This [图片类型] gives information about [读标题].
2.  From this picture, we can see X axis shows [], and Y axis shows[].
    可补充：And the [X/ Y] axis is from [数值] to [数值].
3.  In this picture, we can see [词汇1], [词汇2], and [词汇3].
    如果图里字少: In this picture, we can see some colors, such as [], [], and [].
4.  Well, it is clear that the highest number is ..., which is [对应横坐标]。
    可补充：And the second biggest number is ..., which is [对应横坐标]
-.  However we can see the lowest number is [最小数值] which is [对应横坐标]
    可补充：Also, we can find the second lowest number is..., which is [横坐标].
(5).动态：趋势分析，随时间变化的趋势
    [动态‼️]Overall, the trend is [going up/ going down], and the trend is changing [quickly/ slowly]. (总体趋势上升/下降)
    静态：元素间的大小、高低对比
    [静态‼️]Also, [名字A] is much [bigger/ smaller] than [名字B]
6.  In conclusion, this [图片类型/ picture] tells us about [主题/标题].
    All in all, the picture gives information about [主题/标题].

[流程图]
1.The given picture is a flow chart, which is about [主题/标题].
2.There are several [stages/ steps] in this process. 
3.The first step is [读图里第一个框的字/词].
  Next, we can see [读中间某个框的词].
  Then, we can see [读另一个框的词]
  Finally, the last [stage/step] is...
4.In conclusion, this picture is very informative.
5.So according to the given chart, we can get the information about [主题/标题].

[地图/纯图]
1.This picture gives information about [读标题]
2.In this picture, we can see ... and ...
3.At the top of this picture, there is ...
  We can see ... on the left side as well.
  And on the right, we can see ...
  At the bottom, we can see ...
4.In the middle of the picture, we can find ...
5.So in conclusion, this picture shows [主题/标题].
描述顺序：上->左->右->下->中(不会遗漏、重复)
